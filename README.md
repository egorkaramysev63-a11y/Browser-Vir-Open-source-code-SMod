### 🚀 Core Evolution: From Power X (PX) to the New Era of Kt PX / NewMater

The **Power X (PX)** series was originally created as a powerful tool completely focused on **maximum performance and hardware acceleration**. The interface delivers a stable 60-120 FPS thanks to deep memory optimization. 

**What lies ahead for the project after PX?**
We are officially transitioning to a new, ultra-modern architecture called **Kt PX (Kotlin Power X)** and the graphic engine **NewMater (New Material)**! This is a global step forward that takes operation speed to a completely different level. All media modules and internal utilities are fully separated from the old WebView engine and operate as independent, native system components. 

⚠️ **Important System Announcement:**
Official support and development of the older **PX** and **PX Lite** branches will be completely **discontinued in version 1.6.1**. All future development, bug fixes, and new features will be built exclusively within the next-generation **Kt PX / NewMater** ecosystem. 

### 🛠️ Global Goals & New Development Standards:

* **⚡ Total Native Software Separation:** All system tools (Calendar, Notes, Calculator, Backup, and Chat) no longer depend on web pages. They are written as full, separate screens, which saves RAM and heavily reduces the load on the CPU.
* **🌍 Global International Localization:** Implementation of a built-in system for instant interface switching into 12 different languages (including Russian, English, and Chinese) on the fly while the application is running.
* **🛡️ Absolute Leader Security:** Transition to a three-level automatic protection system (high-speed AdBlock, dangerous domain blocker, and a system anti-spy shield that completely blocks hidden screen recording).
* **📱 MIUI Style Interface Philosophy:** Creation of the lightest, most responsive, and most comfortable graphic shell. It features easy navigation controls and a clean home screen layout, making the user's life much easier.
